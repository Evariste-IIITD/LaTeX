# $\LaTeX$

This repository will contain our $\LaTeX$ templates for POTW's, SPT's, ZPC's and more.

I have also added a [latex.json]{latex.json} which contains a VS Code snippet for automatically and quickly get the barebones template for problems and solutions of the POTW when working in VS Code.

This is also hosted as a website, serving [index.html](index.html), which is converted to HTML from Markdown [IntroToLaTeX](IntroToLaTeX.md), and are notes for learning $\LaTeX$.
